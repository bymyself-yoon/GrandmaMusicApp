# 업데이트 배포 방법 (가족 설정의 "업데이트" 버튼)

가족 설정 → 업데이트 칸의 **"업데이트" 버튼**을 누르면, GitHub에 올린 최신 버전을 받아서 바로 설치해.
노래가 나오고 있으면 끄고 설치해. 버튼을 누를 때만 인터넷이 필요하고, 저절로 확인하지는 않아.

## 처음 한 번만

1. **GitHub 저장소 만들기** (예: `grandma-music`, Public)
   - Private 저장소는 로그인 없이 파일을 받을 수 없어서 안 돼
2. **주소 넣기**: `app/build.gradle.kts`의
   ```kotlin
   val updateJsonUrl = "https://github.com/OWNER/REPO/releases/latest/download/update.json"
   ```
   에서 `OWNER/REPO`를 내 GitHub 아이디/저장소 이름으로 바꿔 (예: `suyuni/grandma-music`)
3. 이 버전을 **USB로 한 번** 할머니 폰에 설치해 (Android Studio ▶ Run)
4. 할머니 폰 → 앱 → 가족 설정(3초 꾹) → **업데이트** 칸에서
   - "설치 권한 허용하기"를 누르고 허용해

## 새 버전을 낼 때마다

1. 코드를 고쳐
2. `app/build.gradle.kts`에서 **`appVersionCode`를 1 올려** (예: 2 → 3). `appVersionName`도 바꿔 (예: "1.2.0")
3. Android Studio 오른쪽 **Gradle** 탭 → `app` → `Tasks` → `distribution` → **`makeUpdate`** 더블클릭
   - `app/build/update/` 폴더에 `update.json`, `grandma-music.apk`가 생겨
4. GitHub 저장소 → **Releases → Draft a new release**
   - Tag: `v1.2.0` 처럼 아무 이름
   - 위 두 파일을 끌어다 놓고 **Publish release**
5. 할머니 폰을 와이파이(또는 데이터)에 연결하고, 가족 설정 → 업데이트 → **"업데이트"** 버튼을 눌러
   - 설치 확인창이 뜨면 "업데이트"를 눌러줘

## 알아둘 점

- **첫 업데이트는 설치 확인창에서 "업데이트"를 한 번 눌러야 해.**
  그 뒤로는 안드로이드 12 이상(갤럭시 A31 포함)이면 버튼 없이 조용히 설치될 수 있어.
- 업데이트해도 **넣어둔 노래와 재생목록은 그대로 남아.**
- **`app/signing/grandma.keystore`는 절대 지우거나 바꾸지 마.** 이 키가 바뀌면 업데이트가 안 되고,
  앱을 지웠다 다시 깔아야 해 (그러면 노래도 다 지워져). 구글 드라이브 말고 다른 곳에도 백업해두면 좋아.
- `appVersionCode`를 안 올리면 앱이 "최신 버전"이라고 생각해서 설치를 안 해.
